# 📊 FinSight — 규칙 기반 기업 재무·리스크 분석 엔진

## 1. 한 줄 소개

국내 상장사의 **OpenDART 사업보고서**를 받아 **5대 재무 리스크 점수(100점) · DuPont ROE 3단계 분해 · 현금전환주기(CCC) · 최근 1년 공시 위험**을 한 화면에 정리하는 **규칙 기반(결정론적 Python) 분석 엔진**입니다.

> **"AI"를 붙이지 않은 이유** — 모든 수치 계산(DuPont·CCC·리스크 판정)은 `analyzer.py`의 **결정론적 Python 규칙**이며,
> LLM 추론이나 생성 모델에 의존하지 않습니다. 같은 재무제표를 넣으면 언제나 같은 숫자와 같은 판정이 나옵니다.

## 4. 이 프로젝트가 해결하는 문제

1. **DART 사업보고서는 한 회사에 100쪽이 넘습니다.** "이 회사가 위험한가?"를 5분 안에 판단하기 어렵습니다. → 5개 지표·100점으로 요약합니다.
2. **ROE 한 줄로는 수익의 출처를 알 수 없습니다.** 빚으로 올린 ROE와 이익을 남겨 올린 ROE는 위험도가 전혀 다릅니다. → DuPont 3단계로 쪼개고, 두 회사의 ROE 격차를 요인별로 분해합니다.
3. **이익이 나도 현금이 묶여 있으면 위험합니다.** → 매출채권·재고·매입채무로 현금전환주기(CCC)를 계산해 운전자본 부담을 보여 줍니다.

## 5. 주요 기능

**화면 (Streamlit 웹 앱)**

- **기업 검색 + 경쟁사 1곳 비교** — 이름 일부만 넣어도 검색됩니다(추천: 삼성전자·SK하이닉스·현대자동차·NAVER·카카오).
- **상단 요약** — 기업별 ① 5대 리스크 종합 점수(100점 🟢🟡🔴) ② 최근 1년 공시 위험 건수 ③ 최신 매출액 ④ 영업이익률, 그리고 **1차 스크리닝 한계 고지**.
- **① 핵심 재무 & 추이** — 재무제표 표(억원·천 단위 구분자), 손익·재무상태 차트, 7대 재무비율 표와 추이 차트.
- **② FP&A 심층** — DuPont ROE 3단계 분해(순이익률 × 총자산회전율 × 재무레버리지, 단순 ROE 검산), 두 회사 ROE 격차 요인 분해(순차 대체법), DSO·DIO·DPO·CCC 표와 차트.
- **③ 리스크 상세 & DART 원문** — 5개 항목 신호등 표(판정 기준·메모 포함), 항목별 나란히 비교, 최근 1년 공시 제목의 위험 키워드와 원문 링크, 연도별 사업보고서 링크.
- **두 가지 레이아웃** — `app.py`(사이드바 설정형) / `app_v2.py`(사이드바 없는 중앙 집중형, 분석 실행 시 결과로 부드럽게 스크롤).

**엔진 · 도구**

- **CLI + HTML 대시보드** — `python3 analyzer.py 삼성전자 SK하이닉스` 로 콘솔 요약과 `report_삼성전자_vs_SK하이닉스.html` 을 만듭니다(Chart.js, 파일 하나로 동작).
- **계산은 한 곳에** — 앱과 CLI 모두 `analyzer.py` 의 함수(`build_analysis` · `compute_ratios` · `compute_working_capital` · `evaluate_risk` · `build_dupont_gap` …)를 호출만 합니다.
- **결정론적 규칙 기반** — 모든 계산·판정이 Python 규칙이라 결과가 재현됩니다(LLM 미사용).
- **단위 테스트** — `tests/test_analyzer.py` 가 네트워크 없이 비율·DuPont·CCC 계산을 검증합니다(23개 케이스).
- **인증키 처리** — `st.secrets["DART_API_KEY"]` → 환경변수 → (없을 때만) 화면 입력 순서. 코드에 하드코딩하지 않습니다.

### 5-1. 지표 계산식

| 구분 | 지표 | 계산식 | 읽는 법 |
| --- | --- | --- | --- |
| 수익성 | 영업이익률 | 영업이익 ÷ 매출액 × 100 | 매출 100원 중 본업에서 남긴 이익 |
| 수익성 | 순이익률 | 당기순이익 ÷ 매출액 × 100 | 이자·세금까지 반영한 최종 이익률 |
| 수익성 | ROE | 당기순이익 ÷ 자본총계 × 100 | 주주 자본으로 번 수익률 (15% 이상이면 우수한 편) |
| 안정성 | 부채비율 | 부채총계 ÷ 자본총계 × 100 | 100% 이하면 안정적, 200% 초과는 주의 |
| 안정성 | 유동비율 | 유동자산 ÷ 유동부채 × 100 | 100% 미만이면 단기 지급 부담 |
| 성장성 | 매출액 증가율 | (당기 − 전기) ÷ \|전기\| × 100 | 외형 성장 속도 (YoY) |
| 성장성 | 영업이익 증가율 | (당기 − 전기) ÷ \|전기\| × 100 | 전기가 적자면 `*` 표시 (참고치) |
| 수익성 | 순이익률 (DuPont) | 당기순이익 ÷ 매출액 × 100 | ROE 분해의 1단계 — “얼마나 남기는가” |
| 효율성 | 총자산회전율 (DuPont) | 매출액 ÷ **기말** 자산총계 | ROE 분해의 2단계 — “자산을 얼마나 빨리 돌리는가” (단위: 회) |
| 안정성 | 재무레버리지 (DuPont) | 자산총계 ÷ 자본총계 | ROE 분해의 3단계 — “빚을 얼마나 썼는가” (단위: 배) |
| 수익성 | DuPont ROE | 순이익률 × 총자산회전율 × 재무레버리지 | 위 ROE와 같은 값이 나와야 정상 (검산) |
| 운전자본 | DSO | (기말 매출채권 ÷ 매출액) × 365 | 매출채권을 현금으로 바꾸는 데 걸리는 일수 |
| 운전자본 | DIO | (기말 재고자산 ÷ 매출원가) × 365 | 재고가 팔리기까지 걸리는 일수 |
| 운전자본 | DPO | (기말 매입채무 ÷ 매출원가) × 365 | 매입 대금을 언제까지 미루는지(길수록 유리) |
| 운전자본 | CCC | DSO + DIO − DPO | 현금이 묶여 있는 기간(일). 짧을수록 운전자본 부담이 작음 |

> ROE는 **기말 자본총계** 기준으로 단순 계산했습니다. 기업분석 보고서에서 쓰는
> (기초+기말)/2 평균자본 기준과는 값이 조금 다를 수 있습니다.
> DuPont ROE도 같은 기준(기말 자산·기말 자본)으로 재계산하며, 두 값의 차이는 반올림 오차(0.00%p)뿐이어야 합니다.
> CCC의 분자(매출채권·재고자산·매입채무)도 **기말잔액** 기준입니다.

## 6. 한계

- **연결재무제표 우선**: 종속회사까지 합친 연결(CFS) 기준입니다. 연결이 없으면 별도(OFS)로 자동 대체되며, 어느 쪽을 썼는지 콘솔과 HTML 하단에 표시됩니다.
- **사업보고서만 사용**: `reprt_code=11011`(사업보고서)만 조회합니다. 분기 실적은 반기·분기 코드로 바꾸면 되지만, 이 프로그램은 연간 비교에 맞춰져 있습니다.
- **금융회사는 일부 지표가 비어 있을 수 있습니다**: 은행·보험사는 재무상태표에 `유동자산/유동부채` 구분이 없고 손익계정도 `순이자손익` 구조라 `-` 로 표시됩니다. 일반 제조·서비스 기업에 최적화되어 있습니다.
- **공시 시점 차이**: 사업보고서는 보통 다음 해 3월에 공시됩니다. 그래서 "최근 3개년"은 자동으로 **작년·재작년·그 전년**을 시도하고, 실제로 데이터가 있는 연도만 사용합니다.
- **이자보상배율의 이자비용**: 회사가 `이자비용`을 따로 공시하지 않으면 `금융비용`(이자비용 + 외환·파생 손익 등)으로 계산합니다. 그래서 실제 이자 부담보다 보수적으로(낮게) 나올 수 있습니다.
- **리스크 점수의 한계**: 5개 항목·3단계 판정이라 **같은 등급 안의 미세한 차이는 점수에 반영되지 않습니다.** 두 회사가 모두 100점이면 "둘 다 안전하다"까지만 말하고, 우열은 수익성·성장성 지표로 판단해야 합니다. 업종별 기준값(예: 건설업 부채비율)도 반영하지 않았습니다.
- **투자 판단용이 아닙니다**: 학습·포트폴리오 목적의 요약 도구이며, 투자 권유가 아닙니다.
- **이 평가는 1차 스크리닝입니다**: 과거 결산 재무제표와 공시를 훑는 수준이며, 업종별 구조 차이(금융업·건설업 등)와 금리·환율·업황 같은 향후 시장 변수는 반영하지 않습니다. 업종 비교군과 원문 공시를 함께 봐야 합니다.
- **DuPont의 총자산회전율은 기말 자산 기준**입니다. 자산이 급증한 해(예: SK하이닉스 2025년 자산 176.1조)에는 평균자산 기준보다 회전율이 낮게 나옵니다.
- **CCC는 기말잔액·365일 기준**이며, 매출원가를 공시하지 않는 회사는 N/A입니다. 업종 간 비교(유통 vs 장치산업)보다는 같은 회사의 추세를 보는 데 적합합니다.
- **공시 위험 키워드는 오탐·누락이 있습니다**: 공시명에 키워드가 없어도 위험할 수 있고, 반대로 단순 유상증자도 사업 확장 목적이면 위험이 아닐 수 있습니다.

## 7. 로컬 실행 방법

**준비물** — Python 3.10 이상, OpenDART 인증키(무료 40자리, <https://opendart.fss.or.kr> → 오픈API → 인증키 신청), 인터넷 연결.

```bash
# 1) 저장소 받기
git clone https://github.com/m02n0627-glitch/finsight-ai.git
cd finsight-ai

# 2) 의존성 설치 (streamlit · plotly · pandas)
python3 -m pip install -r requirements.txt

# 3) 인증키 넣기 (둘 중 하나)
export DART_API_KEY="발급받은_40자리_키"          # Windows: set DART_API_KEY=...
# 또는 .streamlit/secrets.toml 파일에: DART_API_KEY = "발급받은_40자리_키"
#     (형식 예시는 .streamlit/secrets.toml.example)

# 4) 웹 앱 실행 — 브라우저가 자동으로 열립니다 (http://localhost:8501)
streamlit run app.py        # v1 · 사이드바 UI
streamlit run app_v2.py     # v2 · 중앙 집중형 UI
```

```bash
# (선택) 터미널에서 바로 분석하고 HTML 대시보드 만들기
python3 analyzer.py 삼성전자 SK하이닉스 --years 2023 2024 2025

# (선택) 계산 로직 단위 테스트 — DART 호출 없이 0.3초
python3 -m pip install pytest
python3 -m pytest tests/ -v
```

> `corp_codes.json`(기업 목록 캐시)과 `report_*.html` 은 첫 실행 때 자동으로 생기며 `.gitignore` 로 제외됩니다.
