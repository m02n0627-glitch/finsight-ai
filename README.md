# FinSight

**규칙 기반 기업 재무·리스크 분석 엔진**

국내 상장사의 OpenDART 사업보고서를 받아 리스크 점수(100점), DuPont ROE 3단계 분해, 현금전환주기(CCC), 동종업계 비교, 최근 1년 공시 위험, **3표(손익·재무상태·현금흐름)가 연결된 FP&A 3개년 시나리오**를 한 화면에 정리합니다.

계산은 모두 `analyzer.py`의 결정론적 Python 규칙입니다. LLM 추론이나 생성 모델을 쓰지 않으므로, 같은 재무제표를 넣으면 언제나 같은 숫자와 같은 판정이 나옵니다.

## 화면

**상단 요약** — 기업별로 리스크 점수 · 매출액 · 영업이익률 · 공시 위험 네 숫자와 `원문 ↗` 링크만 남겼습니다. 원문 링크는 기업 카드 헤더의 **한 개**(`{최신연도} 원문 ↗` → 재무제표 직행 `report/viewer.do`, 시드/라이브 실패 시 사업보고서 표지로 폴백)뿐이라 같은 링크가 위·아래에 두 번 뜨지 않습니다. 2개사 비교에서도 카드마다 하나씩 붙습니다.

**① 핵심 재무 & 추이** — 핵심 재무제표 표와 차트 2개. 표의 모든 숫자를 클릭하면 그 해 DART **재무제표 원문**(`report/viewer.do`)이 새 탭으로 열립니다. 추가 계정·세부 차트는 접어 두었습니다.

**② FP&A 심층** — DuPont ROE 3단계 분해(순이익률 × 총자산회전율 × 재무레버리지, 단순 ROE 검산), 두 회사 ROE 격차 요인 분해(순차 대체법), DSO·DIO·DPO·CCC. 기업 한 곳만 분석했을 때는 탭 하단에 **동종업계 자동 비교**가 붙습니다.

**③ 리스크 상세 & DART 원문** — 5개 항목 신호등 표와 판정 기준, 최근 1년 공시 제목의 위험 키워드, 연도별 사업보고서 링크.

**④ FP&A 시나리오** — 최신 결산 실적을 출발점으로 **매출 성장률(−30~+40%) · 판관비 중 고정비 비중(0~100%) · CCC 변동(−45~+45일) · 매출 대비 CAPEX(0~30%)** 네 가정만 바꿔 **Y+1~Y+3 손익계산서 · 현금흐름표(FCF) · 재무상태표(기말 현금)** 를 이어서 계산합니다. 보수적(Bear)·기준(Base)·낙관적(Bull) 3개 기본 시나리오와 내 시나리오를 나란히 비교하고, 출발점 카드(현금·CAPEX·이자비용) · 매출 경로 차트 · 시나리오 비교표 · 내 시나리오 연도별 상세표 · 핵심 인사이트 2~3줄 · 공시 데이터 한계 고지를 보여 줍니다. 슬라이더를 움직이면 실행 버튼 없이 바로 다시 계산됩니다. (v2 전용 — `app.py`는 3개 탭 구성)

**📥 엑셀(.xlsx) 리포트** — 결과 상단의 `📥 엑셀(.xlsx) 리포트 다운로드` 버튼 한 번으로 4개 시트를 받습니다. `요약 및 리스크`(총점·등급·5대 항목·공시 위험) / `재무제표 및 비율`(억원·천 단위 쉼표, 7대 비율, 자본잠식 표기) / `DuPont 및 CCC`(3요인 분해·순차 대체법 격차·DSO/DIO/DPO/CCC) / `동종업계 및 공시`(피어 비교표·공시 위험 목록과 DART 원문 URL). 파일명은 `FinSight_{기업명}_{기준연도}.xlsx` (두 기업이면 `FinSight_{A}_vs_{B}_{기준연도}.xlsx`)입니다. ## DART 원문 직행 링크

재무제표 숫자와 기업 카드의 `원문 ↗` 은 DART 뷰어의 **재무제표 한 장**(`report/viewer.do`)으로 바로 갑니다. 표지(`dsaf001/main.do`)가 아니라 손익계산서·재무상태표·현금흐름표 중 그 숫자가 있는 표로 열립니다.

| 단계 | 동작 |
| --- | --- |
| ① 시드 | `statement_links_seed.json` — 주요 상장사 **161개사 · 2023~2025 사업보고서 653건**의 접수번호·직행 링크·목차 이름. 네트워크 없이 즉시 반환. `build_statement_links_seed.py`로 다시 만들 수 있음(공개 화면만 사용 — API 키 불필요) |
| ② 실시간 | 시드에 없는 접수번호만 `main.do` HTML의 목차를 파싱해 `viewer.do` 링크를 만듦 (연결손익계산서 → 손익계산서 순) |
| ③ 폴백 | 한 장짜리 목차를 못 찾으면 ‘연결재무제표’ 목차로, 그래도 실패하면 사업보고서 표지(`main.do`)로 — 링크가 비지 않게 |

반환값의 `source`(`seed` / `live` / `fallback`)로 어느 경로였는지 알 수 있습니다. 시드에는 접수번호·링크·목차 이름만 있고 API 키·재무수치는 없습니다. Streamlit Cloud(미국 리전)처럼 `main.do` 조회가 느리거나 막히는 환경에서도 주요 기업은 시드로 바로 열립니다.

```bash
git clone https://github.com/m02n0627-glitch/finsight-ai.git
cd finsight-ai
python3 -m pip install -r requirements.txt

export DART_API_KEY="발급받은_40자리_키"      # Windows: set DART_API_KEY=...
# 또는 .streamlit/secrets.toml 에: DART_API_KEY = "발급받은_40자리_키"

streamlit run app.py        # v1 · 사이드바 UI
```

```bash
# CLI · HTML 대시보드
python3 analyzer.py 삼성전자 SK하이닉스 --years 2023 2024 2025

# 계산 로직 단위 테스트 (네트워크 불필요)
```

## 판정 기준 — 업종 평균 대비 위치 + 4대 최소 경보선

주요 지표 카드에는 `양호 · 보통 · 부담` 같은 절대 컷을 두지 않습니다. 업종마다 적정 마진·부채 수준·현금 주기가 달라 한 숫자로 자를 수 없기 때문입니다. 판정은 두 갈래뿐입니다.

| 갈래 | 내용 |
| --- | --- |
| 주 근거 | 같은 업종 피어의 실측 평균 대비 **높음 / 낮음**(사실)과 **우위 / 열위**(지표 방향을 반영한 판정 — 부채비율·CCC는 낮을수록 우위) |
| 예외 | 업종과 무관하게 위험 신호로 보는 **최소 경보선(4종)** — ① 자본잠식(자본총계 0 이하) ② 영업이익률 0% 미만(적자) ③ 유동비율 100% 미만 ④ 이자보상배율 1배 미만 |

경보선은 숫자 옆에 은은한 회색 라벨로만 붙고, 그 밖의 좋고 나쁨은 업종 평균 대비 위치가 맡습니다. 5대 리스크 점수(100점)는 이와 별개로 남겨 둔 1차 스크리닝입니다.

## 동종업계 자동 비교

기업 한 곳만 골라 분석하면 탭 ② 하단에 **같은 업종 상장사와의 비교**가 붙습니다. "이 회사가 업종 안에서 어디쯤인가"를 보기 위한 것으로, 업종 코드로 피어를 자동 선정합니다.

| 단계 | 규칙 |
| --- | --- |
| 업종 코드 | OpenDART `company.json`의 `induty_code`(KSIC 10차 기준). 저장소 시드 `industry_map_seed.json`(118개사) 우선, 없으면 실시간 조회 |
| 피어 선정 | ① 동일 코드 → ② 같은 3자리(소분류) → ③ 같은 2자리(중분류) 순으로 최대 3개사. 같은 단계에서는 업종군이 같은 회사 → 시드의 표본 순서(규모 순) |
| 지주회사 | `64992`(지주회사)는 자회사 업종이 제각각이라 일반 기업 피어에서 제외하고, 지주회사끼리만 비교 |
| 비교 지표 | 영업이익률 · ROE · 부채비율 · 유동비율 · CCC (최신 기준 연도) |
| 조회 방식 | 선정된 피어(최대 3곳)의 OpenDART 재무제표를 `ThreadPoolExecutor(max_workers=3)`로 **동시 조회**. 표 순서는 선정 순서 그대로이고, 한 곳이 실패하면 그 피어만 빠지고 나머지·본 분석은 그대로 남음 |
| 상대 위치 | 피어 평균·중앙값 대비 차이와 순위(피어 포함). 요약 문장은 이상치에 덜 흔들리는 **중앙값** 기준 |

> **업종코드는 DART 신고값입니다.** 실제 사업 구성과 다를 수 있습니다(예: 삼성전자 `264` '통신 및 방송장비 제조업' — 실제 주력은 반도체). 그래서 화면에는 코드와 함께 업종군 이름(예: `반도체·전자`)을 쓰고, 3자리→2자리로 넓혀 피어를 채운 사실을 표에 표시합니다. 업종 비교는 **참고 정보**이며, 네트워크·API가 실패하면 비교 없이 본 분석만 그대로 진행됩니다.

## 3표 연결 FP&A 시나리오 시뮬레이터

탭 ④ — 최신 결산 연도의 실제 OpenDART 수치(손익계산서 · 재무상태표 · 현금흐름표)를 출발점으로 두고, 네 가지 가정만 바꿔 Y+1~Y+3의 3표를 이어서 펼칩니다. 엔진은 `analyzer.py`의 `simulate_fpa_scenarios()` 하나이고, LLM·확률·난수를 쓰지 않는 순수 함수라 같은 입력이면 언제나 같은 숫자가 나옵니다. 슬라이더를 움직이면 실행 버튼 없이 바로 다시 계산됩니다.

| 가정 | 범위 | 기본값 | 의미 |
| --- | --- | --- | --- |
| 연간 매출 성장률 | −30 ~ +40% | 0% | 매년 같은 성장률이 3년 반복 |
| 판관비 중 고정비 비중 | 0 ~ 100% | 70% | 매출이 줄어도 그대로 나가는 판관비 몫 → **영업레버리지** |
| 운전자본 회전일수(CCC) 변동 | −45 ~ +45일 | 0일 | +면 현금이 더 오래 묶임(유출) |
| 매출 대비 CAPEX | 0 ~ 30% | 최근 공시 `유형자산의 취득 ÷ 매출`, 미공시 0% | 설비투자 강도 |

| 단계 | 계산식 |
| --- | --- |
| 매출액(n) | 매출액(0) × (1 + 매출 성장률)^n |
| 매출원가(n) | 매출액(n) × (매출원가(0) ÷ 매출액(0)) — 매출을 따라가는 변동비 |
| 판관비(n) | 판관비(0)×고정비 비중 + 매출액(n) × 판관비(0)×(1−고정비 비중) ÷ 매출액(0) |
| 영업이익(n) | 매출액(n) − 매출원가(n) − 판관비(n) + 기타손익(0) |
| 영업이익률(n) | 영업이익(n) ÷ 매출액(n) × 100 |
| 이자보상배율(n) | 영업이익(n) ÷ 이자비용(0) — **1배 미만이면 경보** |
| EBITDA(n) | 영업이익(n) + 감가상각비(0) |
| 운전자본(n) | 매출액(n) ÷ 365 × CCC(n), CCC(n) = CCC(0) + 변동(일) |
| 운전자본 증감(n) | 운전자본(n) − 운전자본(n−1) — 양수면 현금이 묶임 |
| CAPEX(n) | 매출액(n) × 매출 대비 CAPEX ÷ 100 |
| 잉여현금흐름(FCF)(n) | EBITDA(n) − 운전자본 증감(n) − CAPEX(n) − 이자비용(0) |
| 기말 현금성자산(n) | 기초 현금성자산(0) + 누적 FCF(n) — **0 아래면 현금 고갈 경보** |

| 시나리오 | 매출 성장률 | CCC 변동 |
| --- | --- | --- |
| 보수적 (Bear) | −10% | +20일 |
| 기준 (Base) | 0% | 0일 |
| 낙관적 (Bull) | +10% | −20일 |
| 내 시나리오 | 슬라이더 −30~+40% | 슬라이더 −45~+45일 |

고정비 비중·CAPEX 비율은 네 시나리오 모두 기업의 기본값(고정비 70% · 공시 CAPEX 비율)을 공통으로 쓰고, 성장률과 CCC만 다르게 둡니다.

- **영업레버리지가 숫자로 드러납니다.** 예전 모델처럼 영업이익률을 사용자가 직접 정하지 않고, 매출원가·판관비 구조와 고정비 비중에서 이익이 따라 나옵니다. 고정비 비중을 올리면 매출이 늘 때 영업이익이 더 빠르게 늘고, 매출이 줄 때 더 크게 나빠집니다.
- **기타손익(0)** 은 `공시 영업이익 − (매출 − 매출원가 − 판관비)`의 차이를 출발 연도 수준으로 유지합니다. 그래서 성장률 0인 기준 시나리오는 출발 연도 영업이익을 그대로 재현합니다.
- **운전자본은 ‘매출 1일분 × CCC’로 근사**합니다. 공시된 DSO·DIO·DPO에서 나온 CCC를 그대로 쓰면서 매출채권·재고자산·매입채무 잔액을 해마다 따로 추정하지 않는 단순법입니다.
- **자본잠식·영업적자 기업도 그대로 계산**합니다(나눗셈 없음). 출발점이 적자면 이익률이 음수로 이어지고, 자본잠식이면 화면에 경고를 함께 띄웁니다.
- **공시가 비어 있는 계정은 지어내지 않습니다.** 매출원가·판관비가 없으면(금융업 등) 영업이익률을 출발 연도 수준으로 고정하는 예전 방식으로 물러나고, CCC가 없으면 운전자본 변동을 FCF에 넣지 않으며, 이자비용·현금성자산·감가상각비가 없으면 각각 `-`(미공시)로 두고 경보 판정을 건너뜁니다. 0으로 나누는 계산은 없습니다.
- **감가상각비가 빠지는 회사는 FCF가 작게 나옵니다.** DART API가 현금흐름표의 ‘조정’ 세부 항목을 합계 한 줄로만 주는 회사(예: 삼성전자)는 감가상각비가 미공시로 잡혀 EBITDA가 영업이익과 같아집니다. 화면에는 참고로 공시된 `영업활동현금흐름 − CAPEX`도 함께 적습니다.
- 가정값이 슬라이더 범위를 벗어나거나 숫자가 아니면(문자열·NaN) 범위 안 값으로 잘라 계산합니다.
- 결과는 화면·표에만 쓰이고 엑셀 리포트(4개 시트)와 CLI HTML은 기존 그대로입니다.

- **투자 판단용이 아닙니다**: 과거 결산 재무제표와 공시 제목을 훑는 1차 스크리닝이며, 업종별 구조 차이와 금리·환율·업황 같은 향후 변수는 반영하지 않습니다. 학습·포트폴리오 목적의 도구이고 투자 권유가 아닙니다.
- **FP&A 시나리오는 단순 민감도입니다**: 매출 성장률·판관비 고정비 비중·CCC 변동·매출 대비 CAPEX 네 가정만 반영하고, 법인세·배당·차입 상환·조달·환율·금리는 반영하지 않습니다. 3개년 모두 같은 가정을 반복하므로 해마다 달라지는 실제 계획과는 다릅니다. 실제 실적 전망이나 투자 권유가 아니며, 가정을 바꾸면 결과도 달라집니다.
- **FP&A의 감가상각비는 공시 API에 없을 때가 많습니다**: DART `fnlttSinglAcntAll`은 현금흐름표의 ‘조정’ 세부 항목(감가상각비 등)을 합계 한 줄로만 주는 회사가 있습니다(예: 삼성전자). 그런 회사는 감가상각비가 미공시로 잡혀 EBITDA = 영업이익, FCF가 그만큼 **작게(보수적으로)** 계산됩니다. 화면에는 공시된 `영업활동현금흐름 − CAPEX`를 참고치로 함께 적습니다. 매출원가 안에 섞인 감가상각비와 회사의 실제 수주·CAPEX 계획은 공시되지 않아, 이 시뮬레이션은 고정비 비중·CAPEX 비율 가정에 기댑니다.

</details>
