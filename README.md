# FinSight

**규칙 기반 기업 재무·리스크 분석 엔진**

국내 상장사의 OpenDART 사업보고서를 받아 리스크 점수(100점), DuPont ROE 3단계 분해, 현금전환주기(CCC), 최근 1년 공시 위험을 한 화면에 정리합니다.

계산은 모두 `analyzer.py`의 결정론적 Python 규칙입니다. LLM 추론이나 생성 모델을 쓰지 않으므로, 같은 재무제표를 넣으면 언제나 같은 숫자와 같은 판정이 나옵니다.

## 화면

**상단 요약** — 기업별로 리스크 점수 · 매출액 · 영업이익률 · 공시 위험 네 숫자와 `원문 ↗` 링크만 남겼습니다.

**① 핵심 재무 & 추이** — 핵심 재무제표 표와 차트 2개. 표의 모든 숫자를 클릭하면 그 해 DART **재무제표 원문**(`report/viewer.do`)이 새 탭으로 열립니다. 추가 계정·세부 차트는 접어 두었습니다.

**② FP&A 심층** — DuPont ROE 3단계 분해(순이익률 × 총자산회전율 × 재무레버리지, 단순 ROE 검산), 두 회사 ROE 격차 요인 분해(순차 대체법), DSO·DIO·DPO·CCC.

**③ 리스크 상세 & DART 원문** — 5개 항목 신호등 표와 판정 기준, 최근 1년 공시 제목의 위험 키워드, 연도별 사업보고서 링크.

**📥 엑셀(.xlsx) 리포트** — 결과 상단의 `📥 엑셀(.xlsx) 리포트 다운로드` 버튼 한 번으로 4개 시트를 받습니다. `요약 및 리스크`(총점·등급·5대 항목·공시 위험) / `재무제표 및 비율`(억원·천 단위 쉼표, 7대 비율, 자본잠식 표기) / `DuPont 및 CCC`(3요인 분해·순차 대체법 격차·DSO/DIO/DPO/CCC) / `동종업계 및 공시`(피어 비교표·공시 위험 목록과 DART 원문 URL). 파일명은 `FinSight_{기업명}_{기준연도}.xlsx` 입니다.

두 가지 레이아웃을 제공합니다. `app.py`는 사이드바 설정형, `app_v2.py`는 사이드바 없는 중앙 집중형입니다.

**엔진** — CLI로도 같은 분석을 돌릴 수 있습니다. `python3 analyzer.py 삼성전자 SK하이닉스` 는 콘솔 요약과 `report_삼성전자_vs_SK하이닉스.html`(Chart.js, 파일 하나로 동작)을 만듭니다. 앱과 CLI 모두 `analyzer.py`의 함수만 호출합니다.

## 빠르게 실행

준비물: Python 3.10 이상, OpenDART 인증키(무료 40자리, <https://opendart.fss.or.kr> → 오픈API → 인증키 신청), 인터넷 연결.

```bash
git clone https://github.com/m02n0627-glitch/finsight-ai.git
cd finsight-ai
python3 -m pip install -r requirements.txt

export DART_API_KEY="발급받은_40자리_키"      # Windows: set DART_API_KEY=...
# 또는 .streamlit/secrets.toml 에: DART_API_KEY = "발급받은_40자리_키"

streamlit run app.py        # v1 · 사이드바 UI
streamlit run app_v2.py     # v2 · 중앙 집중형 UI
```

```bash
# CLI · HTML 대시보드
python3 analyzer.py 삼성전자 SK하이닉스 --years 2023 2024 2025

# 계산 로직 단위 테스트 (네트워크 불필요)
python3 -m pip install pytest
python3 -m pytest tests/ -v
```

`corp_codes.json`(기업 목록 캐시)과 `report_*.html` 은 첫 실행 때 자동으로 생기며 `.gitignore`로 제외됩니다. 기업 목록은 저장소의 `corp_codes_seed.json`을 먼저 쓰므로, 첫 실행에서 3.6MB `corpCode.xml` 다운로드를 기다리지 않습니다(다운로드가 막히는 환경에서도 화면이 멈추지 않습니다).

## 리스크 점수

항목당 20점(안전 20 / 주의 10 / 위험 0), 데이터가 없는 항목은 분모에서 제외하고 100점으로 환산합니다.

| 항목 | 판정 기준 |
| --- | --- |
| 유동비율 | 150% 이상 안전 · 100~150% 주의 · 100% 미만 위험 |
| 부채비율 | 100% 이하 안전 · 100~200% 주의 · 200% 초과 위험 · 자본잠식(자본총계 0 이하)은 위험 |
| 이자보상배율 | 3배 이상 안전 · 1~3배 주의 · 1배 미만 위험 |
| 현금흐름의 질 | 영업현금흐름·순이익 동반 흑자 안전 · 순이익 흑자이나 현금흐름 적자 위험 · 동반 적자 위험 |
| 지급능력 | 연속 영업적자 없음 + Z″ 2.6 이상 안전 · 1.1~2.6 주의 · 1.1 미만 위험 |

합산 85점 이상 안전, 60점 이상 주의, 60점 미만 위험입니다.
**자본잠식**(자본총계가 0 이하)인 해는 부채비율·ROE·재무레버리지를 계산하지 않습니다. 자본이 음수면 부채비율이 `-1,154%`, 적자인데 ROE가 `+%`처럼 부호가 뒤집혀 실제와 반대로 보이기 때문입니다. 대신 부채비율 항목을 `자본잠식`(위험)으로 표시하고 요약 카드·리스크 코멘트에 `자본잠식 · 자본총계 -4,402억원`처럼 함께 적습니다. 자본잠식인 해는 다른 지표가 멀쩡해 점수가 높아도 **위험 등급으로 고정**합니다(자본잠식 자체가 관리종목·상장폐지 사유).

## 동종업계 자동 비교

기업 한 곳만 골라 분석하면 탭 ② 하단에 **같은 업종 상장사와의 비교**가 붙습니다. "이 회사가 업종 안에서 어디쯤인가"를 보기 위한 것으로, 업종 코드로 피어를 자동 선정합니다.

| 단계 | 규칙 |
| --- | --- |
| 업종 코드 | OpenDART `company.json`의 `induty_code`(KSIC 10차 기준). 저장소 시드 `industry_map_seed.json`(118개사) 우선, 없으면 실시간 조회 |
| 피어 선정 | ① 동일 코드 → ② 같은 3자리(소분류) → ③ 같은 2자리(중분류) 순으로 최대 3개사. 같은 단계에서는 업종군이 같은 회사 → 시드의 표본 순서(규모 순) |
| 지주회사 | `64992`(지주회사)는 자회사 업종이 제각각이라 일반 기업 피어에서 제외하고, 지주회사끼리만 비교 |
| 비교 지표 | 영업이익률 · ROE · 부채비율 · 유동비율 · CCC (최신 기준 연도) |
| 상대 위치 | 피어 평균·중앙값 대비 차이와 순위(피어 포함). 요약 문장은 이상치에 덜 흔들리는 **중앙값** 기준 |

> **업종코드는 DART 신고값입니다.** 실제 사업 구성과 다를 수 있습니다(예: 삼성전자 `264` '통신 및 방송장비 제조업' — 실제 주력은 반도체). 그래서 화면에는 코드와 함께 업종군 이름(예: `반도체·전자`)을 쓰고, 3자리→2자리로 넓혀 피어를 채운 사실을 표에 표시합니다. 업종 비교는 **참고 정보**이며, 네트워크·API가 실패하면 비교 없이 본 분석만 그대로 진행됩니다.

- **연결재무제표 우선**: 종속회사까지 합친 연결(CFS) 기준입니다. 연결이 없으면 별도(OFS)로 자동 대체되며, 어느 쪽을 썼는지 콘솔과 HTML 하단에 표시됩니다. 현금흐름·이자비용 같은 보조 계정도 같은 재무제표(OFS면 OFS)에서 가져옵니다.
- **사업보고서만 사용**: `reprt_code=11011`(사업보고서)만 조회합니다. 연간 비교에 맞춰져 있습니다.
- **금융회사는 일부 지표가 비어 있을 수 있습니다**: 은행·보험사는 재무상태표에 `유동자산/유동부채` 구분이 없고 손익계정도 `순이자손익` 구조라 `-`로 표시됩니다. 일반 제조·서비스 기업에 최적화되어 있습니다.
- **동종업계 비교는 업종코드 신고값에 기댑니다**: `induty_code`는 기업이 등록할 때 신고한 값이라 낡거나 실제 주력과 다를 수 있고, 시드(118개사)에 없는 기업은 피어가 1~2곳으로 줄 수 있습니다. 피어 평균·중앙값은 값이 있는 피어만으로 계산하므로, 금융업처럼 유동비율·CCC가 없는 업종은 그 행이 비어 있습니다. 업종 횡단 비교(유통 vs 장치산업)보다는 같은 업종 안의 상대 위치를 보는 데 적합합니다.
- **공시 시점 차이**: 사업보고서는 보통 다음 해 3월에 공시됩니다. 그래서 "최근 3개년"은 작년·재작년·그 전년을 시도하고, 실제로 데이터가 있는 연도만 사용합니다.
- **이자보상배율의 이자비용**: 회사가 `이자비용`을 따로 공시하지 않으면 `금융비용`(이자비용 + 외환·파생 손익 등)으로 계산합니다. 실제 이자 부담보다 보수적으로(낮게) 나올 수 있습니다.
- **리스크 점수의 한계**: 5개 항목·3단계 판정이라 같은 등급 안의 미세한 차이는 점수에 반영되지 않습니다. 두 회사가 모두 100점이면 "둘 다 안전하다"까지만 말하고, 우열은 수익성·성장성 지표로 판단해야 합니다. 업종별 기준값(예: 건설업 부채비율)도 반영하지 않았습니다.
- **DuPont의 총자산회전율은 기말 자산 기준**입니다. 자산이 급증한 해(예: SK하이닉스 2025년 자산 176.1조)에는 평균자산 기준보다 회전율이 낮게 나옵니다.
- **CCC는 기말잔액·365일 기준**이며, 매출원가를 공시하지 않는 회사는 N/A입니다. 업종 간 비교(유통 vs 장치산업)보다는 같은 회사의 추세를 보는 데 적합합니다.
- **공시 위험 키워드는 오탐·누락이 있습니다**: 공시명에 키워드가 없어도 위험할 수 있고, 반대로 단순 유상증자도 사업 확장 목적이면 위험이 아닐 수 있습니다. 정정공시는 같은 사건이 여러 건으로 늘어납니다. 키워드는 실제 부실 공시명을 기준으로 `채권은행·관리절차`, `기업구조개선·워크아웃`, `기한의이익 상실·채무불이행`, `회생·파산`, `자본잠식`, `상장적격성 실질심사` 등을 넣었지만, 업종에 따라 의미가 달라질 수 있습니다(금융업의 정상적인 채무재조정 등).
- **투자 판단용이 아닙니다**: 과거 결산 재무제표와 공시 제목을 훑는 1차 스크리닝이며, 업종별 구조 차이와 금리·환율·업황 같은 향후 변수는 반영하지 않습니다. 학습·포트폴리오 목적의 도구이고 투자 권유가 아닙니다.
