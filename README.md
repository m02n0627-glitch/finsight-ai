# 📊 OpenDART 재무제표 분석기 (analyzer.py)

국내 상장사의 **사업보고서 재무제표를 자동으로 받아와** 핵심 재무비율을 계산하고,
두 회사를 나란히 비교하는 **HTML 대시보드**를 만들어 주는 프로그램입니다.

파이썬 표준 라이브러리만 사용하므로 **`pip install` 할 것이 없습니다.** 파이썬만 있으면 바로 실행됩니다.

```
python3 analyzer.py 삼성전자 SK하이닉스
        ↓
① 기업 고유번호 자동 검색 → ② 사업보고서 3개년 재무제표 + 최근 1년 공시 목록 수집
        ↓
③ 재무비율 + 5대 리스크 진단(신호등·100점) + DuPont ROE 분해 + 운전자본 CCC + 공시 위험 키워드
        ↓
④ HTML 대시보드 생성 (DART 원문 공시 링크 포함)
```

## 2. OpenDART 인증키 발급 (5분)

1. <https://opendart.fss.or.kr> 접속 → 오른쪽 위 **회원가입** (개인 회원, 무료)
2. 로그인 후 상단 메뉴 **오픈API → 인증키 신청/관리** 로 이동
3. **API 사용환경**(웹/앱), **API 사용용도**(예: 학습·포트폴리오용 재무분석)를 적고 신청 → **개인 회원은 즉시 발급**
4. 발급된 **40자리 문자열**을 복사해 둡니다. (이메일로도 발송됩니다)

> ⚠️ 인증키는 비밀번호와 같습니다. 블로그나 GitHub에 올릴 때는 반드시 가리고,
> 아래처럼 환경변수나 별도 파일로 관리하세요.
>
> ```text
> DART_API_KEY=****************************************
> ```

**호출 한도**: 인증키 1개당 **하루 20,000건**. 이 프로그램은 한 번 실행에
(회사 수 × 연도 수 + 최초 1회 기업목록 다운로드) 번만 호출하므로 개인 사용에는 충분합니다.

```bash

```

### 자주 쓰는 옵션

| 옵션 | 설명 | 예시 |
| --- | --- | --- |
| `--years` | 분석할 사업연도 직접 지정 (생략 시 **최근 3개년**) | `--years 2022 2023 2024` |

```bash

python3 analyzer.py 셀트리온

# 예시: 연도를 직접 지정
python3 analyzer.py 삼성전자 SK하이닉스 --years 2022 2023 2024
```

## 7. 코드는 이렇게 동작합니다

`analyzer.py` 는 4단계로 움직입니다. 함수 이름을 따라가며 읽으면 전체 흐름이 보입니다.

| 단계 | 함수 | 하는 일 |
| --- | --- | --- |
| 1. 회사 찾기 | `sync_corp_codes()` → `find_company()` | `corpCode.xml`(ZIP)을 받아 `corp_codes.json` 으로 캐시하고, 회사 이름으로 `corp_code`(8자리 고유번호)를 찾습니다. |
| 2. 재무제표 받기 | `fetch_statement()` | `fnlttSinglAcnt.json` 에 `corp_code`, `bsns_year`, `reprt_code=11011`(사업보고서)를 넘겨 주요 계정을 받습니다. |
| 2-1. 확장 계정 | `fetch_extra_accounts()` | `fnlttSinglAcntAll.json`(전체 재무제표)에서 **이자비용·영업활동현금흐름·이익잉여금**을 추가로 뽑습니다. 리스크 진단용이며, 실패해도 본 분석은 계속됩니다. |
| 3. 비율 계산 | `compute_ratios()` | 매출액·영업이익·순이익·자산·부채·자본으로 7가지 재무비율과 **DuPont ROE 3단계 분해**(`dupont` 키)를 계산합니다. |
| 3-1. 리스크 진단 | `evaluate_risk()` | 5개 항목을 🟢🟡🔴로 판정하고 100점 종합 점수와 코멘트를 만듭니다. |
| 3-2. 운전자본 | `compute_working_capital()` | `fnlttSinglAcntAll.json`에서 매출원가·매출채권·재고자산·매입채무를 받아 DSO·DIO·DPO·CCC를 계산합니다. |
| 3-3. 공시 위험 | `fetch_disclosure_risks()` | `list.json`(공시검색)으로 최근 1년 공시를 페이지 끝까지 훑어 위험 키워드를 찾고, 실패해도 분석은 계속됩니다. |
| 4. 출력 | `print_console_report()`, `build_html()` | 콘솔 표를 찍고, Chart.js 대시보드 HTML을 만듭니다(공시 원문 링크 포함). |

### API 호출 형태

```text
https://opendart.fss.or.kr/api/fnlttSinglAcnt.json
    ?crtfc_key=인증키
    &corp_code=00126380      # 삼성전자 고유번호
    &bsns_year=2025          # 사업연도
    &reprt_code=11011        # 11011 사업보고서 / 11012 반기 / 11013 1분기 / 11014 3분기
    &fs_div=CFS              # CFS 연결재무제표 / OFS 별도재무제표
```

전체 재무제표(매출원가·매출채권·재고자산·매입채무)는 같은 형식에 엔드포인트만 `fnlttSinglAcntAll.json` 으로 바꿉니다.
공시 목록은 아래 형식입니다.

```text
https://opendart.fss.or.kr/api/list.json
    ?crtfc_key=********
    &corp_code=00126380
    &bgn_de=20251126&end_de=20261126   # 최근 1년
    &sort=date&sort_mth=desc
    &page_no=1&page_count=100          # 한 페이지 최대 100건 → 1년치는 페이지를 넘겨 수집
```

응답은 아래처럼 생겼습니다. 이 중 `account_nm`(계정명)과 `thstrm_amount`(당기 금액)를 뽑아 씁니다.

```json
{
  "status": "000",
  "message": "정상",
  "list": [
    {
      "sj_div": "IS",
      "account_nm": "매출액",
      "thstrm_amount": "333,605,938,000,000",
      "frmtrm_amount": "300,870,903,000,000"
    }
  ]
}
```

### 코드를 읽을 때 알아두면 좋은 두 가지 함정

1. **`fs_div` 를 지정해도 연결(CFS)과 별도(OFS)가 함께 올 수 있습니다.**
   그래서 응답을 받은 뒤 `fs_div` 값으로 한 번 더 걸러 냅니다. (이걸 놓치면 두 재무제표가 섞입니다)
2. **회사마다 계정 이름이 조금씩 다릅니다.** `매출액` / `수익(매출액)` / `영업수익`,
   `당기순이익` / `당기순이익(손실)` 처럼 후보를 여러 개 두고 찾습니다 (`ACCOUNT_SPECS`).

## 8. 재무비율 계산식

| 구분 | 지표 | 계산식 | 읽는 법 |
| --- | --- | --- | --- |
| 수익성 | 영업이익률 | 영업이익 ÷ 매출액 × 100 | 매출 100원 중 본업에서 남긴 이익 |
| 수익성 | 순이익률 | 당기순이익 ÷ 매출액 × 100 | 이자·세금까지 반영한 최종 이익률 |
| 수익성 | ROE | 당기순이익 ÷ 자본총계 × 100 | 주주 자본으로 번 수익률 (15% 이상이면 우수한 편) |
| 안정성 | 부채비율 | 부채총계 ÷ 자본총계 × 100 | 100% 이하면 안정적, 200% 초과는 주의 |
| 안정성 | 유동비율 | 유동자산 ÷ 유동부채 × 100 | 100% 미만이면 단기 지급 부담 |
| 성장성 | 매출액 증가율 | (당기 − 전기) ÷ \|전기\| × 100 | 외형 성장 속도 (YoY) |
| 성장성 | 영업이익 증가율 | (당기 − 전기) ÷ \|전기\| × 100 | 전기가 적자면 `*` 표시 (참고치) |
| 수익성 | 순이익률 (DuPont) | 당기순이익 ÷ 매출액 × 100 | ROE 분해의 1단계 — “얼마나 남기는가” |
| 효율성 | 총자산회전율 (DuPont) | 매출액 ÷ **기말** 자산총계 | ROE 분해의 2단계 — “자산을 얼마나 빨리 돌리는가” (단위: 회) |
| 안정성 | 재무레버리지 (DuPont) | 자산총계 ÷ 자본총계 | ROE 분해의 3단계 — “빚을 얼마나 썼는가” (단위: 배) |
| 수익성 | DuPont ROE | 순이익률 × 총자산회전율 × 재무레버리지 | 위 ROE와 같은 값이 나와야 정상 (검산) |
| 운전자본 | DSO | (기말 매출채권 ÷ 매출액) × 365 | 매출채권을 현금으로 바꾸는 데 걸리는 일수 |
| 운전자본 | DIO | (기말 재고자산 ÷ 매출원가) × 365 | 재고가 팔리기까지 걸리는 일수 |
| 운전자본 | DPO | (기말 매입채무 ÷ 매출원가) × 365 | 매입 대금을 언제까지 미루는지(길수록 유리) |
| 운전자본 | CCC | DSO + DIO − DPO | 현금이 묶여 있는 기간(일). 짧을수록 운전자본 부담이 작음 |

> ROE는 **기말 자본총계** 기준으로 단순 계산했습니다. 기업분석 보고서에서 쓰는
> (기초+기말)/2 평균자본 기준과는 값이 조금 다를 수 있습니다.
> DuPont ROE도 같은 기준(기말 자산·기말 자본)으로 재계산하며, 두 값의 차이는 반올림 오차(0.00%p)뿐이어야 합니다.
> CCC의 분자(매출채권·재고자산·매입채무)도 **기말잔액** 기준입니다.

## 9. 5대 재무 리스크 진단 (신호등 + 100점 점수)

재무비율은 "얼마나 좋은가"를 보여주지만, 투자자가 실제로 알고 싶은 것은 **"이 회사가 위험한가"** 입니다.
그래서 5개 항목을 🟢 안전 / 🟡 주의 / 🔴 위험으로 판정하고, 100점 만점 종합 점수를 함께 냅니다.

| 항목 | 계산 | 🟢 안전 | 🟡 주의 | 🔴 위험 |
| --- | --- | --- | --- | --- |
| 유동비율 | 유동자산 ÷ 유동부채 | 150% 이상 | 100~150% | 100% 미만 |
| 부채비율 | 부채총계 ÷ 자본총계 | 100% 이하 | 100~200% | 200% 초과 |
| 이자보상배율 | 영업이익 ÷ 이자비용 | 3배 이상 | 1~3배 | 1배 미만 |
| 현금흐름 건전성 | 영업활동현금흐름 vs 당기순이익 | 이익·현금 동반 흑자 | 적자이나 현금 창출 | 이익 흑자·현금 적자 / 동반 적자 |
| 연속 적자·부실 예측 | 연속 영업적자 + Altman Z'' | 적자 없음 & Z'' ≥ 2.6 | Z'' 1.1~2.6 | 3년 연속 적자 또는 Z'' < 1.1 |

### 점수 계산 방식

- 항목당 **20점** 만점: 🟢 20점 / 🟡 10점 / 🔴 0점
- 데이터를 못 구한 항목(N/A)은 **분모에서 제외**하고 남은 항목으로 환산합니다.
  → `종합점수 = 획득점수 합 ÷ 평가가능 항목 만점 합 × 100`
- 등급: **85점 이상 🟢 안전 / 60점 이상 🟡 주의 / 60점 미만 🔴 위험**
- 같은 100점이라도 어떤 항목이 N/A였는지 카드에 표시되므로, 점수와 함께 읽어야 합니다.

### Altman Z''-Score (장부가 기준)

```
Z'' = 6.56·X1 + 3.26·X2 + 6.72·X3 + 1.05·X4

X1 = (유동자산 − 유동부채) / 자산총계     ← 운전자본 비중
X2 = 이익잉여금 / 자산총계               ← 누적 이익의 두께
X3 = 영업이익 / 자산총계                 ← 자산이 벌어들이는 이익
X4 = 자본총계 / 부채총계                 ← 장부가 기준 자기자본 비율
```

원래 Altman 모형의 X4는 `시가총액 ÷ 부채총계` 입니다. 이 프로그램은 **시가총액을 쓰지 않고 장부가(자본총계)를 쓰는 Z'' 변형**을 선택했습니다.
이유는 두 가지입니다. 첫째, 비상장사나 시가총액 조회가 안 되는 상황에서도 같은 기준으로 계산할 수 있습니다. 둘째, 주가 등락에 점수가 흔들리지 않아 **재무제표 자체의 부실 가능성**을 봅니다.

**읽는 법**: 2.6 이상 안전 / 1.1~2.6 회색(주의) / 1.1 미만 부실 위험.
3년 연속 영업적자는 모형 점수와 관계없이 🔴로 처리합니다(실적 악화가 구조적인지 보기 위함).

### 데이터가 없을 때 (N/A)

| 상황 | 처리 |
| --- | --- |
| `이자비용` 계정이 없음 | 회사가 공시한 `금융비용`으로 대체하고 카드에 "금융비용 기준" 표시. 둘 다 없으면 N/A |
| 현금흐름표가 없음 | N/A (전체 재무제표 API 호출이 실패한 경우) |
| 은행·보험 등 금융회사 | 유동/비유동 구분이 없어 유동비율이 N/A, 나머지 항목으로 점수 환산 |

### 실제 판정 예시 (2025 사업보고서 기준)

| 기업 | 점수 | 등급 | 주요 내용 |
| --- | --- | --- | --- |
| 삼성전자 | 100점 | 🟢 안전 | 5개 항목 모두 안전 · Z'' 8.0 |
| SK하이닉스 | 100점 | 🟢 안전 | 5개 항목 모두 안전 · Z'' 7.3 |
| 롯데케미칼 | 40점 | 🔴 위험 | 이자보상배율 −1.1배, 3년 연속 영업적자 |
| 태영건설 | 20점 | 🔴 위험 | 부채비율 542%, 유동비율 67.5%, Z'' −0.5 |

> 삼성전자·SK하이닉스가 둘 다 100점인 것은 오류가 아니라 결과입니다. 두 회사 모두 2025년 기준 재무 안전성 지표가 전부 안전 구간에 있습니다.
> 이 경우 **두 회사의 차이는 안정성이 아니라 수익성·성장성에서 갈립니다**(영업이익률 13.1% vs 48.6%).

## 10. DuPont ROE 3단계 분해 — “ROE가 어디서 나왔나”

ROE 한 줄로는 판단이 안 됩니다. 빚을 많이 써서 올린 ROE와 이익을 많이 남겨서 올린 ROE는 위험도가 전혀 다릅니다.
그래서 ROE를 세 요인으로 쪼갭니다.

```
ROE = 순이익률 × 총자산회전율 × 재무레버리지
      (당기순이익/매출액) (매출액/기말 자산총계) (자산총계/자본총계)

단순 ROE(당기순이익 ÷ 기말 자본총계) = DuPont ROE  ← 검산 포인트
```

계산 결과(2025년, 연결):

| 기업 | 순이익률 | 총자산회전율 | 재무레버리지 | DuPont ROE | 기존 ROE | 검산 |
| --- | --- | --- | --- | --- | --- | --- |
| 삼성전자 | 13.6% | 0.59회 | 1.30배 | 10.4% | 10.4% | 0.00%p |
| SK하이닉스 | 44.2% | 0.55회 | 1.46배 | 35.6% | 35.6% | 0.00%p |

### 두 회사의 ROE 격차는 어디서 나왔나 (순차 대체법)

삼성전자의 요인을 하나씩 SK하이닉스 값으로 바꾸면서 ROE가 얼마나 변하는지 누적하면,
세 기여도의 합이 ROE 격차와 정확히 같아집니다(잔차 0).

| 요인 | 삼성전자 | SK하이닉스 | ROE 기여도 |
| --- | --- | --- | --- |
| 수익성(순이익률) | 13.6% | 44.2% | **+23.4%p** |
| 자산효율성(총자산회전율) | 0.59회 | 0.55회 | −2.1%p |
| 재무레버리지 | 1.30배 | 1.46배 | +3.9%p |
| 합계 | ROE 10.4% | ROE 35.6% | +25.2%p |

→ **격차 25.2%p 중 23.4%p(약 93%)가 수익성에서 나왔습니다.** 자산회전율은 오히려 삼성전자가 근소하게 높고(0.59 vs 0.55),
레버리지도 SK하이닉스가 조금 더 쓴 정도(+3.9%p)입니다. 즉 “SK하이닉스가 빚을 써서 ROE를 올렸다”는 해석은 데이터와 맞지 않습니다.

> 순차 대체법은 **어떤 요인을 먼저 바꾸느냐에 따라 개별 기여도가 조금 달라집니다**(수익성 → 자산효율성 → 레버리지 순서로 고정).
> 합계는 항상 같습니다.

## 11. 운전자본 관리 — 현금전환주기(CCC)

FP&A에서 ROE 다음으로 자주 보는 지표입니다. 이익이 나도 현금이 안 들어오면 회사는 버티지 못합니다.

```
DSO = (기말 매출채권 ÷ 매출액) × 365     회수까지 걸리는 일수
DIO = (기말 재고자산 ÷ 매출원가) × 365   재고가 머무는 일수
DPO = (기말 매입채무 ÷ 매출원가) × 365   지급을 미루는 일수
CCC = DSO + DIO − DPO                   현금이 묶여 있는 일수
```

실제 결과(일):

| 기업 | 연도 | DSO | DIO | DPO | CCC |
| --- | --- | --- | --- | --- | --- |
| 삼성전자 | 2023 | 52 | 104 | 23 | 133 |
| 삼성전자 | 2024 | 53 | 101 | 24 | 130 |
| 삼성전자 | 2025 | 56 | 95 | 24 | **127** |
| SK하이닉스 | 2023 | 74 | 148 | 20 | 201 |
| SK하이닉스 | 2024 | 72 | 141 | 24 | 189 |
| SK하이닉스 | 2025 | 68 | 136 | 27 | **177** |

두 회사 모두 3년간 꾸준히 **짧아지는 방향**입니다(삼성전자 133→127일, SK하이닉스 201→177일).
차이는 50일이고, 그 중 대부분이 **DIO(재고 보유 기간) 95일 vs 136일**에서 생깁니다.

### 데이터가 없을 때 (N/A)

| 상황 | 처리 |
| --- | --- |
| 매출원가·재고자산이 없는 업종(은행·보험 등) | DIO·CCC가 N/A |
| 매출원가를 따로 표시하지 않는 회사 | DIO·DPO·CCC가 N/A |
| `fnlttSinglAcntAll.json` 호출 실패 | CCC 전체 N/A, 나머지 분석은 계속 |

### 이 지표를 읽을 때 주의할 점

- **기말잔액 기준**입니다. 교과서식(기초·기말 평균잔액)보다 값이 크게 나올 수 있습니다.
- **DPO는 ‘매입채무’만** 봅니다. 삼성전자는 미지급금(21.4조)이 매입채무(13.0조)보다 커서, 미지급금까지 넣으면 DPO가 달라집니다.
- CCC가 짧다고 무조건 좋은 것도 아닙니다. 재고를 너무 줄이면 판매 기회를 놓칠 수 있습니다.

## 12. 비재무 공시 위험 키워드 (참고 정보)

재무제표는 확정된 과거만 보여줍니다. 소송·횡령·감사의견 거절처럼 **숫자에 아직 반영되지 않은 사건**은 공시 목록에서 찾습니다.

```text
https://opendart.fss.or.kr/api/list.json
    ?crtfc_key=인증키
    &corp_code=00126380
    &bgn_de=20251126&end_de=20261126      # 최근 1년
    &page_no=1&page_count=100             # 한 페이지 100건 (API 상한)
```

탐지 키워드: `소송` `횡령` `배임` `감사의견` `한정` `의견거절` `상장폐지` `관리종목` `불성실공시` `유상증자` `감자` `부도` `회생`

**중요한 함정 — 100건 제한**: 대기업은 1년 공시가 2,000~3,000건입니다. 삼성전자는 최근 1년 **2,916건**이었고,
첫 100건(1페이지)은 **약 3.5개월치**에 불과했습니다. 그 상태로 “위험 공시 없음”이라고 하면 거짓말이 됩니다.
그래서 `total_page`를 따라 끝까지 넘기며(최대 30페이지 = 3,000건) 1년치를 전부 훑고,
화면에 **“공시 2,916건 전체 조회 · 2025-11-26까지”**처럼 실제 조회 범위를 표시합니다.

실제 결과(2025-11-26 ~ 2026-11-26):

| 기업 | 조회 | 탐지 | 내용 |
| --- | --- | --- | --- |
| 삼성전자 | 2,916건 전체 | 0건 | 🟢 최근 1년 주요 위험 공시 없음 |
| SK하이닉스 | 445건 전체 | 8건 (주의) | 유상증자 관련 8건 — 그 중 4건은 정정공시, 4건은 **종속회사** 공시 |

여기서도 함정이 있습니다.

- **정정공시 중복**: 같은 사건이 `[기재정정]`으로 여러 번 올라오면 건수가 늘어납니다. 건수보다 내용을 보세요.
- **종속회사 공시**: 공시명에 `종속회사의주요경영사항`이 붙으면 연결 종속회사의 자본 변동입니다. 모회사 자본이 늘어난 것은 아닐 수 있습니다.

이 항목은 **점수에 반영하지 않습니다**. 키워드만 보는 단순 필터이고, 키워드가 없다고 위험이 없다는 뜻도 아니기 때문입니다.

| HTML이 열리는데 차트가 안 보임 | 인터넷이 끊겼거나 사내망에서 CDN이 차단된 경우입니다. Chart.js 파일을 직접 내려받아 경로를 바꿔 주세요. |
| `report_...html` 을 열었는데 이전 결과 | 브라우저 캐시입니다. `Ctrl+F5`(맥은 `Cmd+Shift+R`)로 새로고침하세요. |

## 14. 알아둘 점 (한계와 해석 주의)

- **연결재무제표 우선**: 종속회사까지 합친 연결(CFS) 기준입니다. 연결이 없으면 별도(OFS)로 자동 대체되며, 어느 쪽을 썼는지 콘솔과 HTML 하단에 표시됩니다.
- **사업보고서만 사용**: `reprt_code=11011`(사업보고서)만 조회합니다. 분기 실적은 반기·분기 코드로 바꾸면 되지만, 이 프로그램은 연간 비교에 맞춰져 있습니다.
- **금융회사는 일부 지표가 비어 있을 수 있습니다**: 은행·보험사는 재무상태표에 `유동자산/유동부채` 구분이 없고 손익계정도 `순이자손익` 구조라 `-` 로 표시됩니다. 일반 제조·서비스 기업에 최적화되어 있습니다.
- **공시 시점 차이**: 사업보고서는 보통 다음 해 3월에 공시됩니다. 그래서 "최근 3개년"은 자동으로 **작년·재작년·그 전년**을 시도하고, 실제로 데이터가 있는 연도만 사용합니다.
- **이자보상배율의 이자비용**: 회사가 `이자비용`을 따로 공시하지 않으면 `금융비용`(이자비용 + 외환·파생 손익 등)으로 계산합니다. 그래서 실제 이자 부담보다 보수적으로(낮게) 나올 수 있습니다.
- **리스크 점수의 한계**: 5개 항목·3단계 판정이라 **같은 등급 안의 미세한 차이는 점수에 반영되지 않습니다.** 두 회사가 모두 100점이면 "둘 다 안전하다"까지만 말하고, 우열은 수익성·성장성 지표로 판단해야 합니다. 업종별 기준값(예: 건설업 부채비율)도 반영하지 않았습니다.
- **투자 판단용이 아닙니다**: 학습·포트폴리오 목적의 요약 도구이며, 투자 권유가 아닙니다.
- **이 평가는 1차 스크리닝입니다**: 과거 결산 재무제표와 공시를 훑는 수준이며, 업종별 구조 차이(금융업·건설업 등)와 금리·환율·업황 같은 향후 시장 변수는 반영하지 않습니다. 업종 비교군과 원문 공시를 함께 봐야 합니다.
- **DuPont의 총자산회전율은 기말 자산 기준**입니다. 자산이 급증한 해(예: SK하이닉스 2025년 자산 176.1조)에는 평균자산 기준보다 회전율이 낮게 나옵니다.
- **CCC는 기말잔액·365일 기준**이며, 매출원가를 공시하지 않는 회사는 N/A입니다. 업종 간 비교(유통 vs 장치산업)보다는 같은 회사의 추세를 보는 데 적합합니다.
- **공시 위험 키워드는 오탐·누락이 있습니다**: 공시명에 키워드가 없어도 위험할 수 있고, 반대로 단순 유상증자도 사업 확장 목적이면 위험이 아닐 수 있습니다.
